04

What this is, and is not

read before trusting it
What it guarantees
  • The restored file is byte-identical to the carrier — verified by SHA-256, not by eye.
  • Locking self-tests by unlocking its own output before it hands you a manifest.
  • The key is required. A wrong key or an edited manifest is refused, not silently mangled.
  • Nothing leaves this machine. Uploads are deleted after an hour.
What it does not do
  • It is not confidentiality. The locked file is a playable video and its residual picture survives.
  • The transcode in step 2 is lossy and drops audio. The carrier is the plaintext, not your original.
  • No sender authentication — anyone with your public key can lock a file to you.
  • For real secrecy, encrypt the file with age or GPG instead.
